title: Semantic tokens
description: Two-phase palette → design-token migration.

Semantic replacements are **architectural**, not purely canonical. The same `bg-amber-200` may mean warning, selection, or decoration — so inference never auto-writes.

## Phase 1 — Analyze

```bash
pnpm exec tailwind-canonicalize tokens analyze . --out proposed.json
```

No source edits. Outputs proposals, conflicts, duplicate token reports, cycles.

## Style usage report (drift) — v2

Inventory **all color utilities** (not only `bg-*`) — `text-black`, `bg-slate-200`, `border-*`, `ring-*`, `fill-*`, gradients, semantic tokens like `text-muted-foreground` — with **HTML/JSX tag** attribution:

```bash
tailwind-canonicalize tokens report . -o styles-report.json --md styles.md
```

JSON includes (paths always POSIX: `src/components/...`, never `src\\...`):

- `utilities[]` — count, channel, kind (`palette` | `semantic` | `arbitrary`), variants, `tags`, `files`, samples  
- `byTag[]` / `byFile[]` / `byDirectory[]` — reverse indexes and hotspots  
- `summary.health` — 0–100 score + semantic/palette ratios  
- `summary.byPalette` / `byShade` / `byVariant` — rollups  
- `theme` — CSS / `@theme` color tokens, unused vars, missing vars for semantic utilities  
- `suggestions[]` — workflow hooks (`add-css-color-token`, file hotspots, …) for updating `globals.css`  
- `drift[]` — multi-color tags, palette mix, unused/missing theme tokens, file hotspots  

Never rewrites source. Feed `suggestions` + `theme.missingForSemanticUtilities` into token/CSS generators, then re-run the report.

## Phase 2 — Apply

```bash
pnpm exec tailwind-canonicalize tokens apply tailwind-tokens.json --write
```

Only explicit mappings, pairs, and recipes in the manifest.

## Dark pairs

```tsx
bg-white dark:bg-slate-950  →  bg-background
```

when the pair is approved and dual-theme values exist.

## Theme CSS

Generates Tailwind v4 `@theme` / `@theme inline` with optional `:root` + `.dark` app variables. Prefers aliasing existing `--warning-subtle` over inventing duplicates.
