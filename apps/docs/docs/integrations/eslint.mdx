---
title: ESLint
description: Compose with ESLint and eslint-plugin-tailwindcss.
---

```json
{
  "scripts": {
    "fix": "tailwind-canonicalize . --write --safe && eslint . --fix",
    "check": "tailwind-canonicalize . --check && eslint ."
  }
}
```

Use `eslint-plugin-tailwindcss` for **class order / invalid names** if you want — not for arbitrary→scale rewrites. That is this tool’s job.

lint-staged:

```json
{
  "*.{js,jsx,ts,tsx}": [
    "tailwind-canonicalize --write",
    "eslint --fix --max-warnings=0"
  ]
}
```
