```text
Parser  →  Extract class candidates (oxc AST)
        →  Resolver (theme + candidates + compare)
        →  Migrations / tokens / recipes
        →  MagicString rewrite
        →  Print
```

## Packages

| Package | Role |
|---------|------|
| `@tailwind-canonicalize/parser` | AST extraction (internal workspace package) |
| `@tailwind-canonicalize/resolver` | Theme, migrations, pipeline (internal) |
| `@tailwind-canonicalize/tokens` | Semantic analyze / apply (internal) |
| `@tailwind-canonicalize/transformer` | MagicString (internal) |
| `@tailwind-canonicalize/compiler` | Project scan, workers, watch (internal; not on npm) |
| `tailwind-canonicalize` | CLI + library — **sole published npm package** |

## Pipeline order

1. Tailwind migrations  
2. Arbitrary canonicalization  
3. Recipe overrides  
4. Semantic mappings (approved / aggressive)  
5. Dark-pair collapse  
6. Duplicate removal  
7. Conflict diagnostics  

Conflict diagnostics use **property-group identity** (value-aware for families like text, border, gradient stops, prose, display). Same group + variants + different values → report only; never rewrite. See [Safety](/docs/safety).

See monorepo `docs/architecture/` for deeper design notes.
