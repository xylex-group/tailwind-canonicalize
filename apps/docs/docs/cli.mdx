## Usage

```bash
tailwind-canonicalize [paths...] [options]
tailwind-canonicalize tokens analyze [paths...] [--out manifest.json]
tailwind-canonicalize tokens apply <manifest.json> [paths...] [--write]
```

```bash
tailwind-canonicalize --help
```

`--help` prints a full flag reference. On a TTY it is **ANSI-colored** (title, sections, flags, examples). Respects `NO_COLOR=1` (plain) and `FORCE_COLOR=1` (force color).

## Core options

| Flag | Description |
|------|-------------|
| `--write` / `-w` | Write rewrites to disk |
| `--check` | Exit 1 if changes would be made |
| `--stdin` | Read source from stdin → stdout |
| `--json` | Machine-readable summary |
| `--verbose` | Full −/+ rewrite blocks + every diagnostic line |
| `--diff` | Line diffs |
| `-o, --report <file>` | Write human report (plain text, no ANSI) to a file. **Requires a path** (`--report report.txt` or `--report=report.txt`). `--report -h` is invalid — use `-h` alone for help. |
| `--safe` | Exact/safe only (default mode) |
| `--review` | Report only; never write |
| `--aggressive` | Review-level migrations / high-confidence inference |

## Tokens / style report

| Command | Description |
|---------|-------------|
| `tokens analyze [paths…]` | Propose semantic color mappings (no writes) |
| `tokens apply <manifest> [--write]` | Apply approved mappings + optional theme CSS |
| `tokens report [paths…]` | **Style usage report** — color frequency + tag attribution + drift (`-o styles-report.json`, `--md styles.md`) |

## Migrations

| Flag | Description |
|------|-------------|
| `--migrate` | Apply versioned class renames |
| `--migrations-only` | Skip arbitrary canonicalization |
| `--from-tailwind <n>` | Source major (e.g. 3) |
| `--to-tailwind <n>` | Target major (e.g. 4) |

## Performance

| Flag | Description |
|------|-------------|
| `--watch` | Watch mode (+ incremental) |
| `--incremental` | Hash cache skip |
| `--workers` | Force worker pool |
| `--concurrency <n>` | Parallelism (default 8) |

## Compile verification

| Flag | Description |
|------|-------------|
| `--strict-compile` | Require Tailwind compile equality |
| `--compile-css` | CSS entry for compiler |

## Exit codes

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | Changes required (`--check`) |
| `2` | Error |

## Conflicts & diagnostics

Utilities that share a **cascade slot** (same property group + variants) but differ in value are **reported, never rewritten**.

- Default report **groups** identical conflicts by property group (counts + top pairs).
- `--verbose` lists sample diagnostic lines per message.
- Conflicts do **not** block other rewrites in the same file.

See [Safety](/docs/safety) for true vs false-positive conflict examples (`prose` + `prose-sm`, gradient position vs color, `flex` + `grid`).
